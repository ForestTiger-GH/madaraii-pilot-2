# RS-CBR-001 — Cross-theme Research Corpus Synthesis

**Mode:** post-theme cross-thematic reconciliation  
**Universe:** `RC-CBR-001` plus `TS-CBR-STRUCT`, `TS-CBR-ID`, `TS-CBR-PRESERVE`, `TS-CBR-SURFACE`  
**Status:** established synthesis input to Scientific Knowledge

## Reconciled problem model

The source universe has two simultaneous properties:

1. it is structurally regular enough that common acquisition, raw preservation, period parsing, matrix extraction, catalog, filter/pivot and export mechanisms are justified; and
2. it is semantically heterogeneous enough that global label-based or geometry-based canonicalization is unsafe.

The coherent system therefore needs a **layered contract** rather than one universal table parser:

- acquisition establishes exact source revision bytes;
- raw cell preservation establishes factual completeness;
- source specifications/adapters interpret recognized structures;
- source-local concept identity preserves statistical meaning;
- common long-form observations expose shared fields and open dimensions;
- explicit mappings optionally relate equivalent concepts across sources;
- bilingual/readable names and 2D views are projections over stable IDs.

This model reconciles usability with source fidelity rather than choosing one over the other.

## Cross-theme definitions

### “All numbers preserved”

Means all stored numeric and formula-cached numeric values from the acquired workbook revisions are present in the raw ledger under exact source-cell provenance. It does not mean every numeric cell is an economic observation. Semantic parsing separately classifies each relevant cell.

### “Unified database”

Means a coherent common data contract and query surface over all source-local observations. It does not require every source to share the same fixed dimension set or every similar concept to be merged.

### “Indicator”

A stable source-local semantic concept/hierarchy plus activated dimensions and measure context. A short display label is not the indicator identity.

### “Duplicate”

Requires a typed relation: repeated carrier, equivalent source concept, overlapping publication, or source revision. Similar label/value/shape alone is not a duplicate proof.

### “Normalization”

Presentation normalization is broad but non-authoritative; semantic normalization is explicit, source-scoped and fail-closed.

## Evidence convergence and dependence

Structural counts, family packs and collision reports share one empirical workbook lineage and are not independent evidence. Official CBR methodology supplies independent definitional evidence for several semantics but does not validate parser implementation. The strongest conclusions arise where workbook structure and official methodology align: activity classifications, stock/flow distinctions, seasonal adjustment, currency/maturity concepts and revision possibility.

## Preserved tensions and trade-offs

### Generic inference versus explicit source specifications

More generic inference reduces manual configuration but increases the chance of false semantic interpretation. Fully hard-coded one-off parsers duplicate mechanics. The evidence supports reusable adapter primitives controlled by explicit source specifications.

### Canonical cross-source taxonomy versus safe source-local truth

A large canonical ontology could simplify user search but cannot be justified comprehensively from the current evidence. Source-local truth plus selective explicit canonical mappings is safer and extensible.

### Short readable names versus exact statistical meaning

Short names improve usability only when the removed qualifiers remain structured dimensions/hierarchy and exact source labels remain traceable.

### Forward compatibility versus correctness

Automatic interpretation of arbitrary future workbook changes cannot be guaranteed. The evidence supports structural tolerance within known contracts and explicit failure on unknown semantic variants.

## What the corpus supports strongly

- complete source census is feasible and has been executed for 41/41 files;
- common lossless raw preservation is feasible independent of source semantics;
- a finite adapter/specification system can cover the observed structural universe;
- a common long observation model can coexist with source-specific dimensions;
- fuzzy label equality is unsafe for semantic identity;
- source revisions/provenance must be first-class;
- internet acquisition can be separated from processing and a local-byte path can share the same pipeline;
- non-aggregating filters/pivots can provide useful 2D surfaces;
- bilingual names must be presentation records over stable IDs.

## What the corpus does not establish

- one complete cross-source canonical indicator taxonomy;
- automatic equivalence of overlapping mortgage/deposit/credit concepts across statistical products;
- a single database technology as uniquely correct;
- a guarantee that future CBR workbook revisions remain structurally compatible;
- official CBR English wording for every source-local Russian concept;
- a need to calculate new economic indicators.

## Downstream engineering implications

Target WHAT can now require: complete raw preservation, source-local semantic coverage, explicit dimensions, provenance, safe revisions/conflicts, bilingual catalog, CSV output, callable query/pivot operations, internet/local acquisition paths and fail-closed unknown variants.

Target HOW may choose a package architecture using OOXML raw extraction plus source specs/adapters and a long-form data store. That choice remains a Product Decision rather than a scientific claim.

## Residual scientific UNKNOWNs

Cross-source semantic equivalence remains intentionally sparse until individually evidenced. Project English translations may require maintenance. Future live-source revisions can introduce new classification/geometry changes.

These UNKNOWNs do not block a trustworthy product because the proposed correctness boundary allows preservation and source-local use without claiming unsupported canonical equivalence.

## Reopen

Reopen corpus synthesis on registry change, materially new source methodology, new independent research, or implementation evidence showing that the layered model cannot represent a source distinction without loss.
