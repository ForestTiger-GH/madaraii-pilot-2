## Fixed implementation choices

- Python 3.10+.
- Core dependencies: `requests`, `openpyxl`, `pandas`; standard `sqlite3`, `zipfile`, XML libraries.
- CSV is portability output; SQLite is local query projection.
- All non-empty raw cells are preserved, with exact `<v>` lexical value where available.
- Semantic values never replace the raw record.
- Source profiles choose row-axis semantics; fuzzy matching never creates canonical identity.
- Repeated period header blocks are supported; exchange-rate composite calendar gets a specialized parser.
- Unknown source variant fails closed at semantic admission while raw evidence remains.
- Pivot has no default aggregation.
